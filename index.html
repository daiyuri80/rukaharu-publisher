YouTube チャンネル「ルカとハルの歴史ミステリー」の運営者が、自分で制作した動画を自分のチャンネルにアップロードするための個人用ツールです。一般には提供していません。

A private, single-user tool the operator of the YouTube channel "ルカとハルの歴史ミステリー" uses to upload self-produced videos to their own channel. Not offered to the public.

本ツールは YouTube API サービス（YouTube Data API v3）を使用しています。本ツールを使うことは YouTube 利用規約に同意することを意味し、データの取り扱いには Google プライバシーポリシーが適用されます。
