RukaHaru Publisher プライバシーポリシー

最終更新日: 2026年10月27日

RukaHaru Publisher（以下「本ツール」）は、YouTube チャンネル「ルカとハルの歴史ミステリー」の運営者が、自分で制作した動画を自分の YouTube チャンネルと TikTok アカウントにアップロードするためだけに使う、個人用の非公開ツールです。一般の方には提供していません。

1. 利用する YouTube API サービス

本ツールは YouTube API サービス（YouTube Data API v3）を使い、運営者自身のチャンネルに動画・タイトル・説明文・サムネイルをアップロードします。本ツールを使うことは、YouTube 利用規約に同意することを意味します。Google によるデータの取り扱いは Google プライバシーポリシーをご覧ください。

1-2. 利用する TikTok API

本ツールは TikTok for Developers の Login Kit と Content Posting API を使い、運営者自身の TikTok アカウントに、運営者が制作したショート動画と説明文を投稿します。TikTok によるデータの取り扱いは TikTok プライバシーポリシーをご覧ください。

2. 取得する情報

YouTube について本ツールが求める権限は次の 3 つだけです。

  • youtube.upload: 運営者のチャンネルに動画とサムネイルをアップロードするため
  • youtube.readonly: アップロードの前に、認証したチャンネルが運営者のチャンネルであることを確認するため（チャンネル ID を読むだけで、保存はしません）
  • yt-analytics.readonly: 運営者自身のチャンネルと動画の統計（再生数・視聴維持率・登録者の増減・サムネイルの表示回数とクリック率など）を読み、動画づくりの改善に使うため。集計結果は運営者にだけメールで届き、公開・共有はしません

TikTok について本ツールが求める権限は次の 3 つだけです。

  • user.info.basic: 認証した TikTok アカウントが運営者のアカウントであることを確認するため（表示名と open ID を読むだけで、保存はしません）
  • video.upload・video.publish: 運営者のアカウントにショート動画と説明文を投稿するため

他のユーザーの個人情報、視聴履歴、コメント、チャンネル統計などは、YouTube・TikTok のどちらからも取得しません。

3. 情報の使い方・保存・共有

  • OAuth の認証トークンは、運営者が管理するサーバー上のファイルにだけ保存し、アクセス権を運営者本人に限っています。
  • TikTok のアクセストークンとリフレッシュトークンも、同じサーバー上のファイルにだけ保存し、アクセス権を運営者本人に限っています。
  • トークンは動画のアップロード・投稿・サムネイルの設定・統計の読み取りにだけ使い、第三者に提供・販売・共有することはありません。
  • 本ツールは Cookie やアクセス解析を使いません。

4. アクセス権の取り消しとデータの削除

Google アカウントのセキュリティ設定から、本ツールへのアクセス権をいつでも取り消せます。TikTok では、アプリの「設定とプライバシー」→「セキュリティ」→「アプリの権限」から取り消せます。取り消した場合やツールの利用をやめた場合、保存していたトークンは 7 日以内に削除します。

RukaHaru Publisher Privacy Policy

Last updated: October 27, 2026

RukaHaru Publisher ("the Tool") is a private, single-user tool used only by the operator of the YouTube channel "ルカとハルの歴史ミステリー" (Ruka & Haru's History Mysteries) to upload videos the operator produced to the operator's own YouTube channel and TikTok account. It is not offered to the public.

1. YouTube API Services

The Tool uses YouTube API Services (YouTube Data API v3) to upload videos, titles, descriptions and thumbnails to the operator's own channel. By using the Tool you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

1-2. TikTok APIs

The Tool uses TikTok for Developers Login Kit and the Content Posting API to post short videos and captions produced by the operator to the operator's own TikTok account. See the TikTok Privacy Policy for how TikTok handles data.

2. Information collected

For YouTube, the Tool requests only three scopes:

  • youtube.upload: to upload videos and thumbnails to the operator's channel
  • youtube.readonly: to confirm, before uploading, that the authorized channel is the operator's own channel (the channel ID is read only and not stored)
  • yt-analytics.readonly: to read analytics for the operator's own channel and videos (views, retention, subscriber changes, thumbnail impressions and click-through rate) to improve future videos. Results are e-mailed only to the operator and never published or shared

For TikTok, the Tool requests only three scopes:

  • user.info.basic: to confirm that the authorized TikTok account is the operator's own account (the display name and open ID are read only and not stored)
  • video.upload and video.publish: to post short videos and captions to the operator's account

It does not access any other user's personal information, watch history, comments or channel statistics on either YouTube or TikTok.

3. Use, storage and sharing

  • The OAuth token is stored only in a file on a server controlled by the operator, readable only by the operator.
  • TikTok access and refresh tokens are likewise stored only in a file on that server, readable only by the operator.
  • Tokens are used only to upload and post videos, set thumbnails and read analytics, and are never sold, shared with or disclosed to third parties.
  • The Tool uses no cookies or analytics.

4. Revoking access and deleting data

Access can be revoked at any time via the Google security settings page. On TikTok, access can be revoked in the app under Settings and privacy → Security → Manage app permissions. Stored tokens are deleted within 7 days after access is revoked or the Tool is no longer used.
